# Zustimmung
- Der Fdl kann eine Zugfahrt mit besonderem Auftrag wie folgt zulassen:

| Befehl       | Signal        | Mündlich       |
|--------------|---------------|----------------|
| 1 | Zs1 |  Zs12 an Hauptsignal
| 2 | Zs7 | |
| 3 | Zs8 | |
| 6 | Sh1 auf Höhe des Esig oder Bksig im Gegengleis| |

# Geschwindigkeit 
- Die maximal zulässige Geschwindigkeit für eine Zugfahrt mit besonderem Auftrag beträgt 40 Km/h
